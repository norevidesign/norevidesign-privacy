NoreviDesign Trend Snapshots — Privacy Policy

Last updated: 28 September 2026

NoreviDesign Trend Snapshots is a private, single-user application used by the NoreviDesign shop for its own product research. This page describes exactly what the application does with data, and what it does not do.

What the application does

Once per day, the application reads aggregated Pinterest Trends keyword data through the Pinterest API. The access is read-only: the application does not create, modify or delete anything on Pinterest.

The data it reads consists of aggregated search-trend information about keywords — for example, which keywords are growing in a region, and their position in a trend list. This information is not about individuals. It is used solely to help decide which product ideas the shop should research further.

What the application does not collect

  • No personal data is collected, stored or processed.
  • No user data of any kind is collected — no profiles, no boards, no pins, no follower information, no behavioural data about any Pinterest user.
  • No third party receives data from the application. Nothing is sold, shared, published, syndicated or transferred to anyone.
  • No tracking, analytics, cookies or advertising are used by the application or by this page.

Storage and retention

The aggregated keyword trend data that the application reads is stored only in a private local database on the shop owner's own computer, and is used only for the shop's internal product research. It is not published and is not accessible to anyone else. Because the data contains no personal information, there is no personal data to access, correct, export or delete.

Who operates the application

The application is operated by the owner of the NoreviDesign shop, for that shop alone. It is not offered to other users, and it has no sign-up, no accounts and no visitors.

Contact

Questions about this policy can be sent through the shop's own message channel on Etsy: norevidesign.etsy.com.

Changes to this policy

If the application's use of data changes, this page will be updated and the date at the top will change with it.
